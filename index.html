/ 02WHY GLIDE

从碎片化资讯，到可决策情报

移民与边境安全是高度敏感、跨语种、跨时区的垂直领域。泛资讯聚合器无法满足研究、决策与现场响应的深度需求。GLIDE 围绕"事件"重新设计了情报工作流。

多源聚合 · 零噪声

NewsNow API（40+ 平台）+ RSS（30+ 源）+ JS 渲染（Obscura CDP），全部优先抓取中文版与官方渠道，第一时间覆盖全球动态。

双重 AI 筛选

关键词硬筛 + LiteLLM 语义评分（0.7 分阈值），事件相关性二次校验，将噪声压到 5% 以下，保留高置信度信号。

事件化治理

同一事件的多篇报道自动聚类、跨源验证、生命周期跟踪；实体抽取构建知识图谱，把新闻列表升级为可追溯的事件库。

/ 08QUICK START

三步启动

三种部署方式覆盖服务器 / 本地开发 / Windows 计划任务场景。

# 1. 克隆
git clone https://github.com/WYHCIPUC/GmwRadar.git
cd GmwRadar

# 2. 配置 .env（必填 AI_API_KEY）
cp .env.example .env

# 3. 启动
cd docker
docker compose up -d
docker logs GLIDE -f
# 1. 安装依赖
python -m venv .venv
.venv\Scripts\activate      # Windows
pip install -r requirements.txt

# 2. 配置 + 体检
cp .env.example .env       # 必填 AI_API_KEY
python -m GmwRadar --doctor

# 3. 启动主程序 + Web 控制台
python -m GmwRadar
python web_server.py       # http://localhost:8000
# 打开「任务计划程序」→ 创建基本任务
# 触发器：每天 / 每 30 分钟
# 操作：启动程序
