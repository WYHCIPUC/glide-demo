/ 02WHY THIS SYSTEM

从碎片化资讯，到可决策情报

移民与边境安全是高度敏感、跨语种、跨时区的垂直领域。泛资讯聚合器无法满足研究、决策与现场响应的深度需求。境鉴围绕“事件”重新设计了情报工作流。

多源聚合 · 持续监测

连接热榜、RSS、公开网页与专题资料，集中跟踪跨语种、跨地区的政策与事件变化。

双重 AI 筛选

结合关键词与语义分析筛选相关内容，生成中文摘要，整理风险线索和重点变化。

事件化治理

同一事件的多篇报道自动聚类、跨源验证、生命周期跟踪；实体抽取构建知识图谱，把新闻列表升级为可追溯的事件库。

/ 03CORE CAPABILITIES

一体化情报工作台

将采集、筛选、治理与分发落地为可操作的工作空间：既看全局趋势，也能进入单个事件的证据链，并把结果沉淀为专题和月度研判。

/ 08QUICK START

灵活选择部署方式

获得项目源码后，可用 Docker、本地 Python 或 MCP 接入。公开介绍页无需安装或登录。

# 1. 进入已取得的项目源码目录
cd GLIDE

# 2. 配置 .env（必填 AI_API_KEY）
cp .env.example .env

# 3. 启动
cd docker
docker compose up -d
docker logs GLIDE -f
# 1. 安装依赖
python -m venv .venv
.venv\Scripts\activate      # Windows
pip install -r requirements.txt

# 2. 配置 + 体检
cp .env.example .env       # 必填 AI_API_KEY
python -m GmwRadar --doctor

# 3. 启动主程序 + Web 控制台
python -m GmwRadar
python web_server.py       # http://localhost:8000
# stdio：适合桌面 AI 客户端
python -m mcp_server.server

# HTTP：适合局域网服务或自动化编排
python -m mcp_server.server --transport http --port 3333
